Collaborative Discussion 1: The 4th Industrial Revolution
Industry 4.0 has enhanced healthcare through AI, IoT devices, cloud systems, and electronic health records, but this increased digital integration has also expanded cybersecurity vulnerabilities. The WannaCry attack on the NHS in 2017 demonstrated how such weaknesses can disrupt essential services, with widespread cancellations and a return to paper-based operations. Peer feedback clarified that the issue stemmed less from outdated technology and more from failures in patch governance and organisational oversight, as many affected systems were supported but unpatched. Additional insights emphasised the importance of network segmentation, secure offline backups, zero‑trust architectures, and tested recovery plans. Together, these contributions highlight that Industry 5.0’s human‑centred resilience requires viewing cybersecurity as a clinical safety priority, ensuring continuity of critical care even during digital disruption.

from numpy import mean from numpy import std from numpy import cov from numpy.random import randn from numpy.random import seed from matplotlib import pyplot as plt import seaborn as sns from scipy.stats import pearsonr seed(1) data1 = 50 * randn(1000) + 100 data2 = data1 + (10 * randn(1000) + 50) covariance = cov(data1, data2) corr, _ = pearsonr(data1, data2) plt.scatter(data1, data2) plt.show() print('data1: mean=%.3f stdv=%.3f' % (mean(data1), std(data1))) print('data2: mean=%.3f stdv=%.3f' % (mean(data2), std(data2))) print('Covariance: %.3f' % covariance[0][1]) print('Pearsons correlation: %.3f' % corr)

3. linear_regression
import matplotlib.pyplot as plt from scipy import stats x = [5,7,8,7,2,17,2,9,4,11,12,9,6] y = [99,86,87,88,111,86,103,87,94,78,77,85,86] slope, intercept, r, p, std_err = stats.linregress(x, y) corr, _ = stats.pearsonr(x, y) print('Pearsons correlation: %.3f' % corr) def myfunc(x): return slope * x + intercept mymodel = list(map(myfunc, x)) plt.scatter(x, y) plt.plot(x, mymodel, color="red") plt.xlabel("X values") plt.ylabel("Y values") plt.title("Linear Regression Example") plt.show()

import pandas as pd import numpy as np import matplotlib.pyplot as plt import seaborn as sns from scipy.stats import pearsonr gdp = pd.read_csv("Unit04 Global_GDP.csv") pop = pd.read_csv("Unit04 Global_Population.csv") desired_years = [str(y) for y in range(2001, 2022)] available_years = [y for y in desired_years if y in gdp.columns and y in pop.columns] gdp[available_years] = gdp[available_years].apply(pd.to_numeric, errors="coerce") pop[available_years] = pop[available_years].apply(pd.to_numeric, errors="coerce") gdp[available_years] = gdp[available_years].interpolate(axis=1).ffill(axis=1).bfill(axis=1) pop[available_years] = pop[available_years].interpolate(axis=1).ffill(axis=1).bfill(axis=1) merged = pd.merge( gdp[["Country Name","Country Code"]+available_years], pop[["Country Name","Country Code"]+available_years], on="Country Code", suffixes=("_gdp","_pop") ) per_capita = merged[[y+"_gdp" for y in available_years]].values / merged[[y+"_pop" for y in available_years]].values per_capita_df = pd.DataFrame(per_capita, columns=available_years) per_capita_df["Country"] = merged["Country Name_gdp"] mean_pop = merged[[y+"_pop" for y in available_years]].mean(axis=1) mean_pc_gdp = per_capita_df[available_years].mean(axis=1) final_df = pd.DataFrame({ "Country": merged["Country Name_gdp"], "Mean Population (2001–2021)": mean_pop, "Mean Per Capita GDP (2001–2021)": mean_pc_gdp }).dropna() plt.figure(figsize=(10,6)) sns.scatterplot( data=final_df, x="Mean Population (2001–2021)", y="Mean Per Capita GDP (2001–2021)" ) plt.xscale("log") plt.yscale("log") plt.title("Mean Population vs Mean Per Capita GDP (2001–2021)") plt.show() r, p_value = pearsonr(final_df["Mean Population (2001–2021)"], final_df["Mean Per Capita GDP (2001–2021)"]) print(f"Pearson Correlation Coefficient: {r:.2f}") print(f"P-value: {p_value:.4f}")
Pearson Correlation Coefficient: -0.10 P-value: 0.1113

import pandas as pd import numpy as np import matplotlib.pyplot as plt import seaborn as sns from scipy.stats import pearsonr gdp = pd.read_csv("C:/Users/User/Desktop/ESSEX/UOL Online/Machine Learning/UNIT4/Global_GDP.csv") pop = pd.read_csv("C:/Users/User/Desktop/ESSEX/UOL Online/Machine Learning/UNIT4/Global_Population.csv") gdp_years = [c for c in gdp.columns if c.isdigit()] pop_years = [c for c in pop.columns if c.isdigit()] years = sorted(set(gdp_years).intersection(set(pop_years))) years = [y for y in years if 2001 <= int(y) <= 2020] gdp[years] = gdp[years].apply(pd.to_numeric, errors="coerce") pop[years] = pop[years].apply(pd.to_numeric, errors="coerce") gdp[years] = gdp[years].interpolate(axis=1).ffill(axis=1).bfill(axis=1) pop[years] = pop[years].interpolate(axis=1).ffill(axis=1).bfill(axis=1) merged = pd.merge( gdp[["Country Name","Country Code"]+years], pop[["Country Name","Country Code"]+years], on="Country Code", suffixes=("_GDP","_POP") ) for y in years: merged[y+"_PCGDP"] = merged[y+"_GDP"] / merged[y+"_POP"] merged["Mean Population"] = merged[[y+"_POP" for y in years]].mean(axis=1) merged["Mean Per Capita GDP"] = merged[[y+"_PCGDP" for y in years]].mean(axis=1) final_df = merged[["Country Name_GDP","Mean Population","Mean Per Capita GDP"]].dropna() final_df.rename(columns={"Country Name_GDP":"Country"}, inplace=True) plt.figure(figsize=(10,6)) sns.scatterplot( data=final_df, x="Mean Population", y="Mean Per Capita GDP" ) plt.xscale("log") plt.yscale("log") plt.title("Mean Population vs Mean Per Capita GDP (2001–2020)") plt.xlabel("Mean Population (log scale)") plt.ylabel("Mean Per Capita GDP (log scale)") plt.grid(True, which="both", linestyle="--", alpha=0.5) plt.show() r, p_value = pearsonr(final_df["Mean Population"], final_df["Mean Per Capita GDP"]) print(f"Pearson Correlation Coefficient: {r:.2f}") print(f"P-value: {p_value:.4f}")

Development Team Project: Project Report
Lecturer Feedback

What was done well:
The report presents a clear business question and maintains a good link between market segmentation and price prediction throughout the analysis. The methodology is structured and applies both regression and clustering techniques appropriately. The decision to exclude price from clustering demonstrates an understanding of avoiding circular analysis. The exploratory analysis highlights the importance of room type and location and uses visualisations to support the findings. Multiple regression models were compared, and the evaluation metrics were presented clearly. The discussion acknowledges the limitations of predictive performance. The recommendations are linked to the results and recognise the need for additional variables to improve prediction accuracy.

What could be improved:
The business rationale could have been developed further. The report explains what was analysed but provides limited discussion of why the findings are strategically important for Airbnb. The regression results show that the best model explained only a small proportion of price variation (R² = 0.146). More critical discussion should have been provided regarding the implications of this low predictive performance. The clustering analysis identifies nine segments, but the discussion remains largely descriptive. You could have explained more clearly how these segments differ from a business perspective and how Airbnb could use them in practice. Some visualisations are presented with limited interpretation. The report would benefit from more explanation of the key insights gained from the figures. Only one reference is included despite several methodological and analytical decisions being discussed. The academic support for the analysis is therefore limited. A significant portion of the report focuses on technical outputs and appendices, while the discussion of business impact and critical evaluation is relatively brief.

General comments for future work:
This report demonstrates a reasonable understanding of regression and clustering techniques and applies them appropriately to the Airbnb dataset. For future work, you should place greater emphasis on explaining the business value of the findings rather than focusing mainly on model outputs and performance metrics. You need to provide deeper critical evaluation of model results, particularly when predictive performance is limited. Explaining what the results mean is often more important than reporting the numbers. You could strengthen the report by providing more academic support, developing the interpretation of the clusters, and offering more detailed business recommendations based on the findings. Overall, the work shows a structured analytical approach, but stronger critical discussion, business interpretation, and justification of conclusions are needed to achieve a higher mark.
